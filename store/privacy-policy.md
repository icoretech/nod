# Nod: Privacy Policy

_Last updated: 18 November 2026_

Nod is a browser extension published by iCoreTech (icorete.ch). Next to the name of each post author on x.com, it shows whether you follow each other ("Mutual"), whether they follow you ("Follows you") or whether they don't follow you ("Doesn't follow you").

## What Nod does with data

- **It reads only what X already sends to your browser.** On x.com, Nod reads the follow status ("follows you", "you follow them") that X includes in the data it loads for the page you are viewing, and uses it to draw the label. From the same page data it also reads which account is signed in, so that your own posts get no label.
- **It keeps that information only in memory**, inside the open x.com tab. It is discarded when you close or reload the tab.
- **It sends nothing anywhere.** Nod makes no network requests of its own. It has no servers, no accounts, no analytics, no telemetry and no tracking.
- **It stores nothing.** Nod does not use browser storage, cookies or any other persistent storage.
- **It sells or shares nothing**, because it collects nothing.

## Permissions

Nod declares no browser permissions. It runs only on `https://x.com/*`, which it needs in order to display the label inside X's pages.

## Changes

If a future version changes any of the above, for example by adding optional features that save settings, this policy will be updated before that version is released, and the change will be described here.
